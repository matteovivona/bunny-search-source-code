# Bunny Search App

This is the copy of the source code of the “Bunny Search” app.

The only difference of this copy with the original is that it uses local database read from a json
file, instead of Firebase Realtime Database. The code used in the original copy can be found by searching the comment
“Used in real app”.

Update: This is a copy of the source code for v1. In 2025, the app was refactored, and v2 was released; the source code of which is not publicly available. Part of the v2 tech stack is Firebase Data Connect, I talked about it at Fluttercon EU '25 (link in the section *Articles & talks*)
